# Gnomicon

Do you hate GNOME? So do I! This is a fairly simple mod that automatically adds a desktop entry for Minecraft so that it has an icon in the dash.

This mod does add files to the user's system, although only if they are using GNOME. These files can be accessed and deleted in `home/your username/.local/share/applications`

For the Fabric source code, check https://github.com/ThePinkPotato/GNOMicon-Fabric
